# Code Evidence — Optional

This starter package intentionally contains **no generated example source code**, because it is meant to prove what you personally implemented in the original graduation project.

Only after confirming permission, add the original files or independently owned reusable implementations you are allowed to publish.

Suggested folders **if those actual files exist**:

- `ultrasound-simulation/` — the exact two implementations you personally worked on, their dependencies, permitted example inputs, and run instructions.
- `ppo-guidance/` — the original environment, PPO training/evaluation scripts, configurations, and small non-sensitive examples.

Keep proper authorship attribution for shared code. Do not silently copy the entire team repo or rewrite other people's code history. Never upload patient-identifying DICOM/CT data, confidential datasets, secret keys, or model weights without permission.

If you cannot share source code, leave `code/` empty except for this README. The public case study can still contain approved technical explanations, plots, and demo recordings.
